# Itau-Figma / Interface gráfica 

## 📌 Sobre o projeto

Projeto de desenvolvimento de uma interface gráfica no Figma, com foco em UI/UX, organização visual e experiência do usuário.

## 🎯 Objetivo

Criar uma interface:

* Intuitiva e fácil de navegar;
* Visualmente organizada;
* Consistente entre as telas;
* Com componentes reutilizáveis;
* Com protótipo interativo.

## 🛠️ Ferramenta

**Figma**

Recursos utilizados:

* Auto Layout
* Componentes
* Protótipo interativo
* Tipografia
* Cores
* Layouts e elementos gráficos

## 🔄 Desenvolvimento

O projeto passou pelas etapas de:

1. Planejamento da interface;
2. Estruturação das telas;
3. Criação do design;
4. Desenvolvimento dos componentes;
5. Prototipação e navegação.
